# COVID-19 Tableau Dashboard Project

## 📌 Project Overview
This project presents an interactive Tableau dashboard built to analyze global COVID-19 trends.  
The dashboard visualizes key metrics such as total cases, total deaths, death rates, infection rates, and regional comparisons.

All datasets were carefully prepared to ensure clean, consistent, and visualization-ready data for Tableau.

---

## 🎯 Project Objectives
- Visualize global COVID-19 key performance indicators (KPIs)
- Compare COVID-19 impact across continents and countries
- Analyze infection rates relative to population size
- Track COVID-19 trends over time
- Present clear insights for data-driven decision-making

---

## 📊 Tableau Dashboards & Visuals
The Tableau dashboard includes:
- Global KPI cards (Total Cases, Total Deaths, Death Percentage)
- Bar charts showing total deaths by continent
- Maps highlighting infection rates by country
- Time-series charts tracking infection trends
- Interactive filters for country and region selection

---

## 📁 Data Preparation for Tableau
The datasets used in this project were:
- Cleaned and aggregated before import
- Structured specifically for Tableau consumption
- Exported to Excel for seamless Tableau connection
- Validated for accuracy and consistency

---

## 📈 Key Insights
- Identified continents with the highest COVID-19 death counts
- Highlighted countries with the highest infection rates
- Revealed variations in death percentages across regions
- Enabled interactive exploration of global COVID-19 data

---

- Tableau
- Excel (data source)
